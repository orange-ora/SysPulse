# SysPulse v1.1.0 更新报告

发布日期：2026-10-07。

本次更新围绕“读数更容易看清，设置更方便调整”重做了下拉面板：四项指标改为双列卡片，设置独立成页，并加入可调原生玻璃、设备信息与轻微点按反馈。

本文截图来自实际运行的当前应用代码，展示与 v1.1.0 相同的界面实现；图片不是生成图。截图中的读数会随机器负载变化，设备信息对应拍摄机器，不是所有用户的固定配置。

## 双列指标面板

![实际应用的主面板](<panel.png>)

主面板宽度为 360 pt，CPU、GPU、内存与网络以 2×2 卡片排列。读数放大、数字等宽，各项标题与曲线使用不同识别色：CPU 青绿、GPU 紫罗兰、内存赭金、网络湖蓝。

- CPU 显示总占用及用户 / 系统占比。
- GPU 显示驱动提供的利用率，以及可读取的核心数与 GPU 内存。
- 内存显示占用比例、已用容量与物理总量。
- 网络突出下载速度，同时保留上传速度与双线历史曲线。

点击卡片会展开对应明细，再次点击或点击关闭按钮可收起。CPU 核心数、GPU 内存、交换分区和本次运行接收 / 发送流量都能在这里查看。

![实际应用的内存明细](<memory-detail.png>)

曲线保存最近 60 个采样点，默认 2 秒刷新时约覆盖 2 分钟。百分比图固定使用 0–100% 量程；网络按当前峰值缩放，下载为实线，上传为较浅虚线。

GPU 沿用每 4 拍采一次的既有节流方式，因此 GPU 曲线中相邻采样点可能沿用同一个读数。运行时长与进程数继续显示在顶部。

## 独立的显示与外观设置

![实际应用的设置页](<settings.png>)

右上角齿轮进入“显示与外观”，左上角返回指标面板。底部的刷新 / 排版文字也可进入同一设置页。

- 刷新频率：0.5、1、2 或 5 秒。
- 菜单栏排版：自动、单行、双行或极简。
- 玻璃通透：0–100%，从厚磨砂调至清透玻璃，自动保存。
- 开机启动：继续使用系统登录项服务，并在操作失败时显示反馈。
- 恢复显示默认值：一次恢复指标显示、刷新频率、排版、光效与通透程度。

调整这些选项时面板保持打开，可以连续修改。恢复显示默认值不会开启、关闭或重置开机启动；首次启动也不会自动注册登录项。

## 默认配置与已有设置

| 项目 | v1.1.0 默认值 |
| --- | --- |
| 刷新频率 | 2 秒 |
| 菜单栏排版 | 自动 |
| 玻璃通透 | 71% |
| 菜单栏光效 | 光晕 |
| 网速、CPU、GPU、内存显示 | 全部开启 |
| 开机启动 | 不属于显示默认值；由用户和系统登录项状态决定 |

这一组基准用于首次启动和“恢复显示默认值”。已有有效设置继续保留，升级不会把用户此前选择的刷新频率或关闭的光效强制改为新默认值。

通透值限制在 0–1；超出范围的有限值会夹到边界，非有限值回退到 0.71。旧的 `off`、`glow`、`diffuse` 存值继续兼容，旧布尔光效配置保留迁移；开发阶段保存的 `breathe` 会迁移并持久化为 `iridescent`。

## 原生玻璃与清晰读数

macOS 26 或更高版本使用系统 Liquid Glass。较高通透区使用清透玻璃，其他区域使用常规玻璃，低通透时再加强磨砂感；macOS 14 / 15 使用原生磨砂材质回退。

通透滑块调节的是材质观感，并非光学透射率或自定义模糊半径。它改变背景、卡片和局部对比底板，读数与曲线本身不会一起变淡。

面板固定使用浅色外观，深色系统下也保持同一套清晰配色；菜单栏文字继续跟随系统外观。

系统开启“减少透明度”时，面板使用实色背景并禁用通透滑块。改变面板通透不会进入菜单栏宽度与锚点的布局决策。

## 统一光效栏与炫彩菜单栏

主面板底部保留独立绿色指标开关，并将光效改为四项连续选择栏：无光效、流光、光晕、炫彩。光效、刷新频率与排版共用同一种布局和选中配色，不再使用旧版下拉效果胶囊。

![实际应用的炫彩选择状态](<panel-iridescent.png>)

新增“炫彩”采用蓝、青、偏蓝紫字面，珠光沿文字扫过。扫光五秒循环，速度固定为 64 pt/s，柔边光带宽 80 pt，中心高亮宽 16 pt。

![实际菜单栏的炫彩效果](<effect-iridescent.png>)

菜单栏图片在面板关闭时拍摄。

炫彩的真实玻璃放在原系统菜单栏按钮内部：macOS 26+ 使用清透 Liquid Glass，旧系统使用菜单磨砂材质。玻璃视图复用，透明占位图保留系统测宽，点击仍交给原按钮；全关指标时继续显示脉搏占位图标。

炫彩刻意使用冷色字面，因此菜单栏在该模式下不显示橙 / 红负载变色。面板中的数值以及其他光效模式仍在 80% / 92% 阈值显示橙 / 红告警。

动效沿用现有 10 fps 计时器与休眠、锁屏、屏保挂起规则。“无光效”停止持续动效刷新。原生菜单栏玻璃属于炫彩模式，其他光效继续使用各自的背景绘制。

## 轻微按压与单块滑动

普通按钮按下时缩至原大小的 98.5%，伴随轻微亮度反馈；按下约 0.08 秒，松开约 0.18 秒恢复，不增加回弹，也不降低文字不透明度。

分段控件的文字保持固定，字重和文字颜色即时切换，只有一块选中底板横向滑动，时长约 0.23 秒。取消旧新高亮交叉淡化，减少拖影感。

系统开启“减少动态效果”时取消按钮缩放和底板滑动，仅保留轻微亮度反馈；设置页切换与玻璃类型切换的过渡也会关闭。

## 当前设备信息与 GPU 提示

面板自动读取当前 Mac 的机型、芯片或处理器、可用核心数与物理内存。启动时先显示 sysctl 和物理内存提供的基础信息，再在后台单次读取系统报告；报告失败或超时保留回退信息，不阻塞主线程，也不加入周期采样。

Apple Silicon 显示统一内存容量与系统提供的类型；Intel 在取得实际 DIMM 字段时按容量和类型显示组合。容量以二进制 GB 表示，不推测未公开的插槽数量、模块或固定机型规格。

GPU 没有读数时，界面区分“等待 GPU 数据”与“该机型未提供计数器”。GPU 利用率、核心数与内存均依驱动提供，不保证所有 Intel Mac 或虚拟机都有完整数据；GPU 内存也不能一律解释为独立显存。

最终动画的普通模式使用未修改的生产源码快照；减少动态效果分支通过隔离测试环境键注入验证，未切换真实系统设置，不能视为系统开关端到端测试。截图存在采集延迟，也不用于证明逐帧位置或精确动画时长。

最低运行系统仍为 macOS 14.0，通用包面向 Apple Silicon `arm64` 与 Intel `x86_64`。源码构建需要 macOS 26 或更新 SDK；较新 SDK 不等于必须在较新系统运行。

此前已完成双架构编译、签名与安装验证，实际运行环境为 Apple Silicon / macOS 27.2；Intel 与 macOS 14 / 15 尚未进行实机运行验证。旧系统磨砂回退和版本判断不能代替这些实机结果。

本版不重复宣称 v1.0.1 的 GPU 量纲、缺值恢复、网络与资源释放修复，也不将 v1.0.2 的唯一正式安装策略列为新增。它们继续保留。旧文档中的 CPU 和窗口内存测量属于历史数据，不能作为新版玻璃和炫彩的性能基准。
