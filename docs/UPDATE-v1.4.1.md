# SysPulse v1.4.1 更新说明

发布日期：2026-10-10。

本次补丁调整设置、退出和返回按钮的悬停外观。默认仅显示图标或文字，鼠标悬停时才显露玻璃底板与轮廓，移开后平滑淡出。

- 设置齿轮与返回箭头采用圆形玻璃框。
- 退出按钮采用圆角玻璃框。
- 保留细亮边、轻微反光、齿轮旋转、返回箭头轻移和按压反馈，按钮出现边框时保持稳定布局。
- 减少动态效果时取消位移、旋转与缩放；减少透明度时沿用实色回退。

指标采样、GPU 92% 黄警 / 97% 红警、详情动画、星点滑条、菜单栏排版和已有偏好沿用 v1.4.0。

## 构建与已有验证

本轮发布前已完成 Apple Silicon / Intel 双架构构建，以及普通、减少动态效果、减少透明度三种分支共 108 项原生专项检查，涵盖按钮悬停、移开恢复、页面导航、布局稳定及玻璃黑块检查。按用户要求，发布阶段不再追加回归或安装包复测；GitHub 发布流程沿用现有构建、签名及打包步骤。

实际原生检查环境为 Apple M5 / macOS 27.2；Intel 与 macOS 14 / 15 尚无实机运行验收。本次为按钮外观补丁，未单独重新测量性能。

支持 macOS 14.0+，提供 Apple Silicon / Intel 通用 DMG 与 SHA-256 校验文件。安装方式见 [README](<../README.md#下载与安装>)，完整历史见 [更新记录](<../CHANGELOG.md>)。
