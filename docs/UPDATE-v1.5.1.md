# SysPulse v1.5.1 更新报告

发布日期：2026-10-12。

本次小版本降低菜单栏「星点」背景的绘制开销，并恢复鼠标悬停时跟随位置的偏转与反光。面板布局、星点外观和已有显示设置继续沿用 v1.5.0。

## 星点性能优化

- 星点固定轨迹参数、粒径与金白颜色预先计算并缓存；每帧只计算当前位置。
- 背景按菜单栏窗口的屏幕倍率生成一次 RGBA 位图，供正常合成与系统菜单栏副本读取，减少同一帧的重复绘制。
- 星点背景直接替换独立图层的图片内容，文字继续按指标采样复用缓存，减少每拍使整个玻璃视图失效的开销。
- 每次效果更新及时释放临时绘图对象；减少动态效果时复用静止帧。静止缓存随尺寸、外观、字形、装饰选项及屏幕倍率失效，仅保留一个当前缓存。
- 星点数量、各自轨迹与速度、金白配色、五缕金丝和彩丝、文字保护区及 **10 fps** 均保留原设计。

## 恢复鼠标偏转

星点模式重新启用原有鼠标追踪。鼠标移入后，背景和字面共同轻微倾斜，反光与边缘亮线跟随鼠标位置；移出后约 0.24 秒平滑复位。Core Animation 合成偏转，星点背景换帧不会重置父层姿态。

点击范围与读数排版保持固定；减少动态效果时取消空间偏转，显示器休眠、锁屏与屏保挂起时清除交互姿态。流光、光晕和无背景的原有选择继续保留。

## 本机性能测量

环境为 **Apple M5 / macOS 27.2，单块内建 Retina 屏幕（2x）**，自动排版实际显示单行，指标每 5 秒刷新。CPU 按进程累计 CPU 时间差除以墙钟时间计算，100% 表示占满一个核心。

| 样本 | 平均进程 CPU | 方法 |
| --- | ---: | --- |
| 优化前的本地星点构建 | 20.09% | 相同正式安装路径、相同偏好，预热 8 秒后测量 20 秒 |
| 性能优化后、恢复悬停前的预览 | 3.45% | 同一轮 A/B，预热 8 秒后测量 20 秒 |
| 恢复悬停后的最终实现预览 | 4.45% | 另一次 20 秒常态采样 |

前两行属于同一轮 A/B，下降约 **83%**；第三行是恢复悬停后的独立样本，因此本版公告概括为本机常态从约 20% 降到约 4%。优化前样本是本地星点实现，其构建指纹为 `54c86a9-dirty@20261012-050554`；最终实现样本为 `8636163-dirty@20261012-132309`，本次升版前已运行。它们属于本地测量，未把旧构建的版本字段当作官方发布版本对比。

这些数值不包括 GPU 或 WindowServer 的 CPU，结果随机器、菜单栏宽度、刷新间隔、指针活动和桌面背景变化。多屏继续通知 AppKit 更新菜单栏副本，但本轮没有多屏实机测量，不据此承诺相同降幅。

外观对比采用浅色 / 深色、三种排版、四个时刻共 **24 个 2x RGBA 画面**，优化前后逐字节一致。另有 1x / 2x / 3x 位图与缓存回归；这些检查覆盖受控渲染，未替代原生 1x、HDR 或混合倍率多屏的视觉验收。

## 最终回归

| 范围 | 结果 | 验证内容 |
| --- | --- | --- |
| 生产代码 | 609 项通过 | CPU / GPU 告警、内存压力、网络计数与时钟、偏好与登录项 mock、四种背景、星点与细丝避字、1x / 2x / 3x 位图、静止缓存失效、面板自然尺寸 |
| 控制器与玻璃 | 60 项通过 | 排版与宿主复用、稳定文字缓存、两帧实际提交的背景图层像素、偏转期间换帧、清空图片后恢复、固定命中区 |
| 面板开合与反向 | 39 项通过 | 初次打开缓出、外层窗口收缩与自然正文、中途反向、过期回调、减少动态效果、帧率适配 |
| 原生面板与菜单栏 | 734 项通过 | 普通、减少动态效果及减少透明度分支，真实窗口像素与交互、设置、详情、面板开合与星点并行、偏转和两帧实际提交像素；另完成 10 个初始原生渲染状态与 1 项设置交互汇总检查 |
| 受控构建打包 | 71 项通过 | 临时安装、真实归档备份、失败回滚、清理、公告图片当前版本优先与历史回退、未来图片排除、缺图与部分图、SHA-256；签名与 DMG 工具采用夹具，正式打包由发布流程校验 |

最终回归同步修正了旧测试夹具：模拟窗口补齐屏幕倍率；星点字面按当前缓存设计检查；面板开合检查沿用 v1.5.0 的缓出与外层收束；原生点击位置和背景选项按当前第二页设置更新。真实偏好与登录项保持隔离，正式安装包另由发布流程执行双架构构建、签名与 DMG 校验。

原生面板测试使用真实 NSPopover、原生鼠标事件和 WindowServer 截图。减少动态效果、减少透明度采用测试进程内的系统属性替换与通知，未切换 macOS 的真实系统设置。菜单栏偏转使用合成 NSEvent 调用真实视图路径，检查追踪区域、倾斜姿态、稳定文字和实际提交的图层像素；本轮没有把它当作物理鼠标事件路由或 WindowServer 菜单栏副本像素的端到端验收。734 项编号检查已包含 31 项控制器与 71 项星点并行动画及背景切换检查，不另行相加。

开发者可执行：

```bash
bash Tools/Regression/run.sh
python3 Tools/Regression/BuildPackagingTests.py
bash Tools/PanelProbe/run.sh
```
