# SysPulse v1.5.0 更新说明

发布日期：2026-10-12。

本版本重做菜单栏的「星点」背景，让蓝紫玻璃更透、金白星点自然散动；同时改进通透滑条、详情收起和面板打开的响应。

## 星点菜单栏

- 原「炫彩」背景更新为「星点」：水蓝、青色与淡紫晕染融合在通透玻璃内，让桌面背景更多透出。
- 金色与白色微星各自沿独立轨迹散动，配上几缕金丝、淡紫、青色和玫瑰色细丝；密度经过收敛，避免遮满背景。
- 星点与细丝避开文字笔画及周围保护区，读数保持清晰；取消这一模式的字面扫光、悬停反光和倾斜。
- 四种背景继续可选：**无背景 / 流光 / 光晕 / 星点**。背景选择移入「显示与外观」设置页，流光与光晕的色彩更鲜明。
- 星点使用独立背景层，数值文字复用缓存；面板开合时背景继续运动，沿用 10 fps 共用时钟。开启「减少动态效果」时星点静止。
- 已有背景选择在升级后保留，原炫彩选择自动显示为星点；新安装默认仍为光晕。星点读数恢复普通指标配色和告警颜色。

## 通透滑条与面板交互

- 通透滑条的蓝紫与青色色场更纯、更轻，加入金色星点。拖动时星点平滑提速，并短暂增加细金星和星尘，松手后自然收敛。
- 无色玻璃滑钮随按压轻微形变，拖动时产生方向性牵引，松手后回弹；滑钮与轨道挖空区域共享姿态，减少快拖时出现的彩色细边。
- 主面板标题与运行信息重新对齐、调整留白；菜单栏背景选项集中到设置页。
- 展开的详情在鼠标离开对应卡片和详情区域后，空闲约 **10 秒**自动收起；鼠标停留时保持展开，移入会取消当前倒计时。
- 面板关闭时只收束外层窗口，内部文字、卡片和曲线保持自然尺寸，减少回收过程的挤压感；快速反向继续从当前状态衔接。

## 打开面板的响应

折叠状态不再提前构建和测量隐藏的详情；首次展开详情时才加载。打开动画更快起步，完整打开动画仍约 0.22 秒。关闭后继续释放面板内容。

本轮修改阶段的同机测量，使用相同的 `sendAction` 派发方式，星点背景与指标采样同时运行：

| 场景 | 修改前的同步准备 | 修改后的同步准备 |
| --- | ---: | ---: |
| 再次打开，第 2 次 | 64.50 ms | 53.03 ms |
| 再次打开，第 3 次 | 72.58 ms | 60.76 ms |
| 进程内首次打开 | 196.72 ms | 203.29 ms |

再次打开的同步准备减少约 11.5–11.8 ms；这组测量未显示首次打开改善，首次仍有约 200 ms 初始化开销。10 ms 间隔采样中的窗口透明度也更早进入可见状态，但这不是 WindowServer 首像素延迟测量，也不代表不同机器上的性能保证。

## 构建与已有验证

本轮修改阶段已完成 **346 项菜单栏背景与命名专项断言、25 项面板开合检查、175 项详情检查、53 项星点与面板并行动画检查**，涵盖真实详情关闭点击、快速反向和文字缓存。按本次发布要求，不再运行回归测试；发布流程执行双架构编译、签名完整性和 DMG 打包校验。

实际运行检查环境为 Apple M5 / macOS 27.2；Intel 与 macOS 14 / 15 尚无实机运行验收。macOS 26+ 使用原生玻璃，旧系统沿用磨砂回退；减少透明度沿用实色回退。

支持 **macOS 14.0+**，提供 **Apple Silicon / Intel 通用 DMG** 和 SHA-256 校验文件。指标采样、CPU / GPU 告警阈值、系统内存压力、登录项和已有显示偏好继续沿用。安装升级见 [README](<../README.md#下载与安装>)，完整历史见 [更新记录](<../CHANGELOG.md>)。
